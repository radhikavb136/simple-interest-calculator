# Simple Interest Calculator

## Description
The Simple Interest Calculator calculates the simple interest earned on a principal amount over a specified period at a given annual interest rate.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

Where:
- **Principal:** The initial amount of money.
- **Rate:** The annual interest rate in percentage.
- **Time:** The duration in years.

## Example
- Principal: 1000
- Annual Interest Rate: 5%
- Time: 2 years

Calculation:

Simple Interest = (1000 × 5 × 2) / 100 = 100

**Simple Interest: 100**

**Total Amount: 1100**

## Features
- Calculates simple interest using the standard formula.
- Accepts principal, rate, and time as inputs.
- Displays the calculated interest and total amount.

## Technologies
This project can be implemented using Python, Java, or JavaScript.
